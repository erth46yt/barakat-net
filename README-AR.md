# تحديث موقع بركات نت — الإصدار 3

## التصليحات
- كل لعبة لها صورة خاصة باسمها، ولا تستخدم ألعابًا أخرى مكان صورتها.
- الألعاب التي ليس لها غلاف أصلي ضمن الصور المتاحة استخدمت لها رسومات تعريفية فريدة وليست صورًا رسمية للعبة.
- صور الرامات الأصلية أعيد تصميم عرضها أفقيًا مع ظهور العبوات. الصورة الأصلية لقطعة 3200 من Kingston؛ راجع الماركة قبل نشر أي مواصفات إضافية.
- بطاقات ألعاب الموبايل أصبحت عمودًا واحدًا بدل عمودين صغيرين.

## الرفع بدون كسر Vercel
1. فك ضغط الأرشيف على الكمبيوتر.
2. افتح مستودع GitHub المرتبط بـVercel على فرع main.
3. ارفع كل محتويات المجلد من الجذر بما فيها مجلد assets بالكامل.
4. نفّذ Commit changes.
5. راقب Deployments في Vercel حتى تصبح Ready.
6. افتح موقعك بتحديث قوي Ctrl+F5.

الموقع ثابت ولا يستخدم قاعدة بيانات. الحجز طلب على واتساب، مش حجز تلقائي مؤكد.
