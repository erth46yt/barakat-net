# موقع بركات نت | BRaKaT NET

موقع عربي RTL متجاوب، ثابت (Static HTML/CSS/JavaScript)، مخصص للنشر على Vercel بدون npm أو أوامر أو قاعدة بيانات.

## نشر الموقع عبر GitHub ثم Vercel (بدون أوامر)

1. افتح https://github.com/new وسجل الدخول، واكتب Repository name مثل `barakat-net`، واختار **Public** أو **Private** ثم **Create repository**.
2. فك ضغط `BarakatNet-GitHub-Vercel.zip` على جهازك.
3. افتح المستودع على GitHub، واختر **uploading an existing file** أو **Add file → Upload files**.
4. اسحب **محتويات المجلد** كلها إلى GitHub: `index.html` و`style.css` و`script.js` و`vercel.json` و`favicon.svg` و`robots.txt` و`README-AR.md` ومجلد `assets`. لا ترفع ZIP كملف وحيد ولا تضع `index.html` في مجلد داخلي.
5. بعد اكتمال الرفع اضغط **Commit changes**. تأكد أن `index.html` ظاهر في الصفحة الرئيسية للمستودع.
6. افتح https://vercel.com/new وسجّل الدخول بحسابك. اختر **Import Git Repository** واربط GitHub بمنصة Vercel إذا طلب منك.
7. اختر `barakat-net` ثم **Import**. Framework Preset: **Other**. Root Directory: `./`. Build Command: **فارغ**. Output Directory: `.`. ثم **Deploy**.
8. بعد أول نشر هتلاقي رابط `*.vercel.app`. أي تعديل في GitHub على فرع الإنتاج الأساسي **main** ثم **Commit changes** ينشر نسخة جديدة تلقائيًا على Vercel.

### تعديل الموقع من GitHub

- الألعاب في `script.js` داخل `GAMES`.
- الأسعار والقطع في `script.js` داخل `PRODUCTS`.
- نصوص الموقع والعروض والعناوين في `index.html`.
- ألوان وأشكال الموقع في `style.css`.
- الصور داخل `assets/`.

اضغط اسم الملف → علامة القلم **Edit** → عدّل → **Commit changes**. احتفظ بنسخة من المشروع قبل تغييرات كبيرة.

### تحديثات هذه النسخة

- إبراز Red Dead Redemption 2 وإضافة GTA IV في مكتبة الألعاب (يرجى تأكيد تثبيت GTA IV قبل إعلانها متاحة).
- قسم أخبار GTA VI بعنوان «قريبًا في بركات نت» بشرط التأكد من التوفر: رسميًا صدرت PS5 وXbox Series X|S بتاريخ 19 نوفمبر 2026؛ نسخة PC لم يتم الإعلان عنها رسميًا وقت إعداد هذه النسخة، ولذلك الموقع لا يدّعي توافرها داخل المحل.
- شرح حفظ تقدم ألعاب التختيم على حساب العميل واستكمالها من أي جهاز مُجهز بالخدمة، بدون اسم نظام الإدارة أمام الزائر.
- قسم أقوى لخدمات التصميم والريلز والتسويق والحملات الإعلانية.
- جميع أقسام المشروع الأصلي وتصميمه وأرقامه وعروضه باقية.

## تشغيله محليًا

افتح `index.html` في المتصفح. البحث والفلاتر ونموذج إعداد رسالة واتساب تعمل بدون سيرفر (مع ضرورة الاتصال بالإنترنت لفتح واتساب والخطوط).

## تعديل الألعاب والقطع والأسعار

- ملف `script.js`: مصفوفة `GAMES` لكل الألعاب، ومصفوفة `PRODUCTS` للكروت والرامات والأسعار.
- ملف `index.html`: نصوص العروض وخدمات المحل وأرقام الاتصال والعنوان وخرائط Google والجروب.
- ملف `style.css`: الألوان والتصميم والمسافات.
- مجلد `assets/`: صور الواجهة والجيمينج والشخصية. الصور المعالجة من تصميمات سابقة **توضيحية وليست صورًا فوتوغرافية موثقة لحالة المكان الحالية**.

## ملاحظات قبل إطلاقه للناس

- ساعات التشغيل الفعلية لم تُثبت بأنها 24 ساعة. الموقع يطلب من الزائر التأكد من الموعد بدل تقديم وعد غير مؤكد.
- سعر الساعة 10 جنيه بدل 20، وأسعار القطع حسب آخر أسعار أعلنها صاحب المحل؛ أكد استمرار العرض وتوفر المخزون قبل النشر.
- عرض 50% لبعض الخدمات ليس لكل الاشتراكات أو لكل الخدمات بلا استثناء.
- حفظ تقدم الألعاب عبر نظام الحسابات مرتبط بتهيئة اللعبة ولا يضمن عمله تلقائيًا مع كل لعبة.
- الألعاب المعروضة تشمل ما تم ذكره في تاريخ المحل؛ تأكد من وجود كل لعبة وتثبيتها حاليًا قبل النشر.
- حجز الموقع ليس حجزًا مؤكدًا؛ النموذج يُنشئ رسالة واتساب فقط، ولا يخزن بيانات الزائر أو يرسلها إلى خادم.
- اللعب الجماعي يتوقف على دعم اللعبة والنسخة ونظام التشغيل، ولا يعني وجود شراكة رسمية مع الشركات المالكة للألعاب.
